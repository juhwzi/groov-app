# Groov — UI/UX Pass

This version applies a broad visual consistency pass based on the current desktop screenshots.

## Main improvements
- More consistent spacing and sizing across panels, forms and controls.
- Reduced button height/padding and removed the oversized visual feel from secondary actions.
- Refined dark-first palette, borders, shadows and radii.
- Improved content width and desktop grid proportions.
- Better sidebar density and active navigation state.
- Cleaner top bar/search field and icon controls.
- More balanced diary hero layout.
- More consistent cards, feeds, covers, badges and list controls.
- Refined profile and Settings layouts.
- Reworked login/register composition to avoid awkward social-button wrapping.
- Better responsive behavior for tablet/mobile widths.
- Added focus states for keyboard/accessibility.
- Added reduced-motion support.

No backend, database, Prisma schema or authentication logic was changed in this pass.
